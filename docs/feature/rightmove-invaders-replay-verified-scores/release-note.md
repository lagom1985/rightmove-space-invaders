# Release note: rightmove-invaders-replay-verified-scores

For players. The reload advice goes out with each of the feature's three releases (D5, D12), wherever the owner publishes release notes.

## Had the game open since before this update? Reload the page

A page left open from before an update can't confirm its signing: you'll see "Couldn't confirm ALX's signing." with your own initials, and your score won't reach the high-score table. Reloading the page fixes it, and every game after that signs as usual.

## What's new

The shared high-score table now takes a score only from a game that really started: each game asks the table for its own session as it starts, and signs with it. Made-up scores sent without a game no longer reach the table. The game looks and plays as before.

**With the second update**, the table also plays each game back before it takes the score: your game sends the moves you made along with your initials, and the table replays them from the start and keeps the deposit the game really reached. A score changed on its way, or one no game could reach, is turned away. Long games still sign in about the usual time.

**With the third update**, a game can't be signed sooner than it could have been played: the table checks that at least the game's own length has passed since it started. Honest players won't notice, because you sign when your game ends, as before. A game played on rules the table has since changed is turned away too, which is why a page left open over an update needs a reload (above).
